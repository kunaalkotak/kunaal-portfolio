# Kunaal Kotak – Portfolio

Personal portfolio for Kunaal Kotak, B.Tech Data Science student at NMIMS MPSTME, Mumbai.

## Overview
A single static page: hero, about, projects, along the way, toolkit and contact. The Projects section is a small tabbed viewer that lays each project out as question, data, approach and result.

## Tech stack
Plain HTML, CSS and vanilla JavaScript in one file (`index.html`). No framework, no build step, no dependencies, no backend. The hero animation is a small canvas drawing; motion is switched off for visitors who prefer reduced motion.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Deploy (free)
- GitHub Pages: push to a public repo, then Settings > Pages > Deploy from branch `main` / root.
- Netlify or Vercel: import the repo. No build command; publish the repo root.
